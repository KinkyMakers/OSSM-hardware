# Recovery sources

The restored documentation was assembled from repository history rather than
from an external documentation service.

| Content | Historical source |
|---|---|
| GitHub-hosted Markdown, images, diagrams, and PDFs | [`9faa8e84`](https://github.com/KinkyMakers/OSSM-hardware/commit/9faa8e846f1be4044aa035b6146db881bed9bf56), the first parent immediately before the Mintlify migration |
| Expanded community mods, including Capstan OSSM XL HG20, the 24 mm DP attachment, and the 60AIM40F motor cover | [`f93133a0`](https://github.com/KinkyMakers/OSSM-hardware/commit/f93133a044e917e2e1efb3438ef9ec83c165352c), before photographs were removed from their original directories |
| Legacy basic-mount guide added after the migration | Current repository history beginning with [`7c09e0af`](https://github.com/KinkyMakers/OSSM-hardware/commit/7c09e0afb6e1276c7057574193056aa8ca49f0ad) |

Generated-site configuration, package dependencies, validation scripts, and
content-sync workflows were deliberately excluded. The files in
`community-docs/` are maintained directly in this repository.
