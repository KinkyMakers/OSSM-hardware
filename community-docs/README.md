# OSSM community documentation

This directory is the in-repository home for community-maintained OSSM
documentation. It preserves the build notes, hardware references, printed-part
guides, community modifications, photographs, diagrams, PDFs, and downloadable
design files that were previously available directly on GitHub.

These files are intentionally plain repository content. They do not depend on
GitBook, Mintlify, or another documentation-site synchronization process. Edit
them directly through normal pull requests so community improvements remain in
the repository history.

## Contributing

Community documentation, inline images, and downloadable design files belong
in this directory. Do not replace the in-repository material with an off-site
redirect. See the project [contribution guide](../CONTRIBUTING.md) for the pull
request workflow.

> OSSM is an experimental machine. Review the [hazards](Documentation/Hazards.md)
> and [safety and design guide](<Documentation/Safety and Design Guide.md>)
> before building or operating one.
