# Radiating PitClamp stand kit

[Editable FreeCAD source](pitclamp-stand.FCStd) · [Four-color Bambu project](pitclamp-stand.3mf)

The rear jaw hinge uses an M5 × 25 mm bolt and M5 nut. The original captured
print-in-place handle stays integrated with the upper jaw. Its bed-facing skin
is blue; the opposite face is black.

The project uses a P2S 0.6 mm nozzle, 0.2 mm layers, 8 walls and 15% gyroid.
AMS slots: 1 blue, 2 pink, 3 white, 4 black. One-arm kit: plates 1–5, 16 pieces.
Two-arm kit: plates 6–12, 32 pieces. Select the kit you need.

Digital mesh, color and clearance checks passed. Physical release, hardware
fit and strength still need testing. This is a part library/print kit; the
existing full stand assembly is not regenerated here.
